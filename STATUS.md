# État du projet

## 2026-08-26 — Initialisation de faisabilité

Le projet a été créé comme dépôt distinct et privé prévu pour une recherche rétrospective, reproductible et non clinique sur des données ouvertes du cancer du pancréas.

| Sujet | Décision |
| --- | --- |
| Finalité | Évaluer la stabilité inter-cohortes d’associations transcriptomiques pré-spécifiées. |
| Données initiales | Aucune donnée individuelle téléchargée ou versionnée. |
| Source pilote recommandée | MetaGxPancreas, après gel de version et examen de ses métadonnées. |
| Code Apamea | Préservé dans son dépôt d’origine ; non copié ni exécuté ici comme code biomédical. |
| Seuils et partitions Apamea | Interdits pour la survie, les patients et toute décision clinique. |
| Validation | Leave-one-cohort-out, analyses de sensibilité et documentation d’incertitude obligatoires. |
| Usage clinique | Hors périmètre. |

## Condition avant toute analyse de données

Avant le premier téléchargement autorisé, il faut figer la version de la source choisie, constituer un manifeste de données, vérifier les conditions d’usage, arrêter la définition de la signature transcriptomique et confirmer que le projet restera rétrospectif et non clinique.

## Condition avant tout modèle prédictif

Tout projet qui dépasserait une association de recherche devra faire l’objet d’un nouveau protocole, d’une revue par un clinicien du PDAC et un biostatisticien, d’une évaluation TRIPOD+AI/PROBAST+AI et d’une confirmation explicite de l’utilisateur avant exécution.
